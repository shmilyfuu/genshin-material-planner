鸣潮声骸计算器 v1.0.0

使用方式
1. 双击“鸣潮声骸计算器.exe”。
2. 拖入、点击上传或按 Ctrl+V 粘贴声骸截图。
3. 核对五条识别结果；属性与档位都可以通过下拉框修改。
4. 选择声骸 1—5 的记录位置，然后确认写入。
5. 五件全部录入后，右侧显示原始总分与最终平均分。

计分说明
- 最终平均分 = 五件声骸小计之和 ÷ 5。
- 方案 A：共鸣效率、普攻伤害加成、重击伤害加成、共鸣技能伤害加成、共鸣解放伤害加成统一计 0 分。

本地数据
- OCR 模型随应用提供，识别在当前电脑完成。
- 记录与 WebView2 数据位于程序目录下的 data 文件夹。
- 复制整个应用文件夹时，可以一并带走现有记录。

运行要求
- Windows 10 或 Windows 11，64 位。
- 需要 Microsoft Edge WebView2 Runtime。Windows 11 通常已包含该组件。
